# Airora — world radio

Listen to 50,000+ live radio stations from 240 countries. Pick a country, tap a station, listen.

- **Website & web app:** https://abhiramupadrashta.github.io/Airora/
- **Downloads:** Android (`Airora.apk`), Windows (`Airora-Setup.exe`) and Mac (`Airora-mac.zip`) on the [latest release](https://github.com/AbhiramUpadrashta/Airora/releases/latest). iPhone: open the web app in Safari → Share → Add to Home Screen.
